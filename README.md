# Sales Data Analysis using Superstore Dataset

## Problem Statement

The objective of this project is to analyze Superstore sales data and identify key business insights related to revenue trends, top-selling products, and profitability.

## Dataset

Dataset: Superstore Sales Dataset

The dataset contains information about:

* Orders
* Sales
* Profit
* Product Categories
* Customer Segments
* Order Dates

## Tools & Technologies

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Jupyter Notebook

## Approach

### 1. Data Loading

Imported the dataset and examined its structure.

### 2. Data Cleaning

* Checked for missing values
* Removed duplicate records
* Converted date columns into datetime format

### 3. Monthly Revenue Analysis

Analyzed sales performance across different months to identify trends.

### 4. Top-Selling Products

Identified products generating the highest sales.

### 5. Profit Analysis

Evaluated profitable and loss-making categories and sub-categories.

## Results

### Monthly Revenue Trends

Revenue showed variations across months, highlighting peak sales periods.

### Top-Selling Products

Several products consistently generated high sales volume and revenue.

### Profit Analysis

Some categories generated high sales but lower profits, indicating areas for business improvement.

## Key Insights

* Identified peak revenue months.
* Determined best-performing products.
* Highlighted profit-driving categories.
* Provided recommendations for improving business performance.

## Conclusion

This analysis provides valuable business insights that can help management make informed decisions regarding sales strategies, product focus, and profitability improvement.
